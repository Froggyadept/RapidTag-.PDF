# RapidTag — установка и запуск

Этот гайд — с нуля, на случай если несёшь программу на компьютер, где
раньше вообще ничего похожего не стояло. Если Python уже стоит — просто
пропусти Шаг 1.

## Шаг 0. Перенеси саму папку с программой

Скопируй всю папку `rapidtag` целиком (со всеми файлами внутри —
`app.py`, `requirements.txt`, `setup.bat`, `start.bat`) на новый ПК —
через флешку, облако (Я.Диск/Google Drive) или просто скачав файлы заново
из чата. Неважно, куда положишь — хоть на Рабочий стол, хоть в Документы,
главное — держать все файлы **вместе, в одной папке**.

## Шаг 1. Проверить, стоит ли Python

Открой **PowerShell**: нажми `Win`, набери `PowerShell`, Enter.

Введи:
```
python --version
```

**Если видишь что-то вроде `Python 3.12.4` или `Python 3.14.5`** — Python
уже стоит, переходи к Шагу 3.

**Если видишь ошибку** (`не является внутренней или внешней командой`,
или Windows открывает Microsoft Store) — Python не установлен или не
добавлен в PATH, переходи к Шагу 2.

## Шаг 2. Установить Python (если нужно)

1. Открой [python.org/downloads](https://www.python.org/downloads/) и
   скачай последнюю версию для Windows (подходит любая 3.10 и новее —
   я проверил, все нужные библиотеки уже поддерживают самые свежие версии
   Python, включая 3.14, дополнительно ничего докручивать не надо).
2. Запусти установщик. **САМОЕ ВАЖНОЕ**: на первом экране установки внизу
   есть галочка **"Add python.exe to PATH"** — обязательно поставь её
   **до** нажатия "Install Now". Это именно та галочка, без которой потом
   Windows не находит команду `python` вообще нигде, как это уже было.
3. После установки **закрой и заново открой PowerShell** (galочка PATH
   применяется только к новым окнам терминала).
4. Проверь снова: `python --version` — теперь должно показать версию.

## Шаг 3. Проверить pip

```
python -m pip --version
```
Обычно ставится вместе с Python автоматически. Если ошибка — переустанови
Python (Шаг 2), в установщике pip идёт "из коробки".

## Шаг 4. Установить зависимости программы

Тут два варианта — простой и ручной.

### Простой способ (рекомендую)
Открой папку `rapidtag` в проводнике и **дважды кликни на
`setup.bat`**. Откроется чёрное окошко, само найдёт свою папку, само
поставит всё нужное. Дождись надписи "Готово!" и нажми любую клавишу.

### Ручной способ (если .bat не запускается / антивирус ругается)
1. Открой папку `rapidtag`.
2. Зажми `Shift` + правая кнопка мыши в пустом месте окна папки →
   **"Открыть окно PowerShell здесь"** (или "Открыть терминал здесь").
3. Проверь, что ты в нужной папке:
   ```
   dir
   ```
   Должны быть видны `app.py` и `requirements.txt`. Если их нет —
   значит PowerShell открылся не в той папке, и `cd` тебе в помощь
   (подробности — см. раздел "Если что-то пошло не так" ниже).
4. Установи зависимости:
   ```
   python -m pip install -r requirements.txt
   ```
   Первая установка займёт пару минут — тянется Streamlit и всё, что ему
   нужно, это нормально.

## Шаг 5. Запуск программы

### Простой способ
Дважды кликни **`start.bat`** в папке программы. Через несколько секунд
само откроется в браузере.

### Ручной способ
В PowerShell, находясь в папке `rapidtag`:
```
python -m streamlit run app.py
```
Откроется `http://localhost:8501` в браузере автоматически. Если нет —
открой этот адрес вручную.

Чтобы остановить программу — вернись в чёрное окошко PowerShell и нажми
`Ctrl+C`, либо просто закрой окно.

## Если что-то пошло не так

**"Could not open requirements file" / "File does not exist: app.py"**
→ PowerShell открыт не в той папке. Убедись, что используешь способ
"Shift + правая кнопка → Открыть PowerShell здесь" **прямо в папке
rapidtag**, а не где-то ещё. Проверяй командой `dir` — должны
быть видны файлы проекта.

**"python: команда не найдена" / открывается Microsoft Store**
→ Python не в PATH. Смотри Шаг 2, не забудь галочку "Add to PATH", и
обязательно **перезапусти PowerShell** после установки.

**Установка зависимостей падает с ошибкой про "Microsoft Visual C++"**
→ Маловероятно (все наши библиотеки ставятся готовыми пакетами без
компиляции), но если увидишь — напиши мне точный текст ошибки, разберём
по факту.

**Windows/антивирус блокирует .bat файл ("Неизвестный издатель")**
→ Это нормальная реакция на новый .bat-скрипт из интернета. Нажми
"Подробнее" → "Выполнить в любом случае", либо используй ручной способ
через PowerShell (там такого предупреждения нет).

**Порт 8501 занят / браузер не открывается**
→ Значит уже где-то запущен другой экземпляр программы. Найди то окно
PowerShell и закрой его (`Ctrl+C`), либо просто открой
`http://localhost:8501` вручную — возможно, программа уже работает.

## Если предстоит показать это коллегам / установить на несколько машин

Повторяешь Шаги 0-5 на каждом компьютере отдельно (Python + библиотеки
ставятся один раз на машину). Если наберётся много рабочих мест —
возвращайся, обсудим вариант с сервером (VPS), чтобы не тащить установку
на каждый комп отдельно — мы это уже обсуждали раньше.
