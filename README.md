# RapidTag v2.1.0 — публичный MVP

Кликовый набор бирок кабелей из PDF-схемы. 

## Быстрый старт

1. Если Python и библиотеки ещё не стоят — см. `install_guide.md`.
2. Дважды кликни `start.bat` (или `python -m streamlit run app.py`).
3. На стартовой странице нажми "🚀 Начать работу" или открой "📖 Шпаргалка"
   (короткая инструкция прямо внутри программы, доступна и позже — через
   боковую панель настроек).

Это публичная демо-версия: активация, USB-привязка и лимит бирок удалены.
Можно свободно запускать приложение и пробовать рабочий сценарий на своих PDF. 
В дальнейшем хочу сделать:
Рефакторинг.
.EXE сборку с мини питоном на борту, чтобы не устанавливать python и билиотеки на рабочую машину.

## Что внутри релиза 2.1.0

**Основной цикл**
- Кликаешь по словам на чертеже — они складываются в бирку
  `сторона1 / сторона2` с настраиваемыми разделителями.
- "Умный сброс" после сохранения — хвост иерархии (например,
  `FTA101:XT1`) остаётся набранным для следующей клеммы того же блока.
- Двойной клик по пустому месту чертежа = быстрое сохранение.
- Автоподсказка второго конца по ссылкам на чертеже (`-FTA102:XT2:C page7`
  находится и распознаётся, даже если в PDF ссылка и номер листа
  склеены без пробела).

**Новое в 1.04.04**
- Переключатели "Снайперский/Пакетный" и "Одиночное/Пара" — второй
  диктует и кнопку сохранения, и двойной клик по чертежу.
- Пакетный режим умеет генерировать диапазоны одиночных бирок (не только
  пар).
- Инлайн-правка бирки прямо в плашке ввода (вместо отдельного экспандера
  "Исправить вручную").
- Таблица сохранённых бирок — правка и удаление строк прямо в ней, плюс
  "Выделить всё" / "Удалить выбранные" / "Удалить всё".
- Своё имя файла для скачивания — вписываешь перед каждым скачиванием.
- Экспорт в Excel (.xlsx) — четвёртой кнопкой рядом с TXT/CSV.
- Служебные хвосты "page"/"reserve" просеиваются из обозначения (включая
  склеенные варианты вроде `201U1page 3` → `201U1`); полезная часть строки
  не отбрасывается целиком.
- Последняя сохранённая бирка видна прямо у поля ввода, без прокрутки.
- Загрузчик PDF, номер страницы и "Найти второй конец" переехали в левую
  колонку — верх страницы больше не растягивается шире рабочей области.


**0.3.3**
- **Заставка + Шпаргалка** — стартовый экран с двумя кнопками, шпаргалка
  продублирована в настройках.
- **Sticky-панель** — строка бирки и кнопки управления (сохранить/сторона
  2/сброс) теперь по-настоящему прилипают к верху при скролле- надо доделать.
- **Настройки (боковая панель)** — вкладки "Маска" (разделители,
  автоподсказка вкл/выкл, игнор-лист) и "Принтер" (параметры этикетки для
  Elegir RT230). Всё сохраняется в `settings.json` рядом с `app.py` —
  руками этот файл трогать не нужно, он просто хранит то, что выбрано в
  интерфейсе.
- **Пакетный режим** — переключатель "🎯 Снайперский / 📦 Пакетный" на
  главной панели. В пакетном режиме набираешь общий хвост один раз,
  задаёшь диапазон "с" / "по" — генерируется вся серия бирок сразу.
  Пока диапазон умеет менять только последнюю числовую часть последнего
  бита (например, `XT1` → `XT2` → ... → `XT10`); более сложные форматы
  (`1.1`, `:+`/`:-`) — следующий шаг, после тестирования базовой версии.
- **Печать под Elegir RT230** — в таблице сохранённых бирок появились
  чекбоксы у каждой строки. Отмечаешь нужные → "Печать выбранных" →
  скачивается `.zpl`-файл с командами для принтера (ширина/высота
  этикетки, DPI, шрифт — настраиваются во вкладке "Принтер"). Файл нужно
  передать на принтер отдельно — прямой отправки по сети пока сознательно
  нет (см. ниже).
- Брендинг: название RapidTag, версия внизу экрана, кликабельная визитка
  (Telegram/почта), лёгкий терминальный/Matrix-флёр в оформлении.

-Осознанно не сделано в этом релизе

- **Печать по сети** — генерируем файл, не отправляем на принтер
  напрямую. Причина: обращение по локальной сети к принтеру — тоже
  "сетевой запрос", хоть и не в интернет, а этот момент решили обсудить
  отдельно позже, не смешивая с текущей доработкой.
- **Горячие клавиши** — сознательно не делаем, двойной клик уже закрывает
  эту потребность без JS-костылей.
- **Мультипринтерность** — целимся в один конкретный принтер (Elegir
  RT230). MK5000 печати не требует, ему хватает CSV-экспорта.
- **`.1`/`.2` и `:+`/`:-` в пакетном диапазоне** — встречаются в реальных
  данных чаще, чем казалось на старте, и слёту не укладываются в простую
  арифметику. Возвращаемся к этому после теста базовой версии на
  практике.

-Файлы в комплекте

- `app.py` — сама программа.
- `settings.json` — локальные настройки (создаётся автоматически при первом
  запуске, если отсутствует).
- `requirements.txt` — зависимости для `pip install -r requirements.txt`.
- `start.bat` / `setup.bat` — запуск и установка одним двойным кликом,
  сами находят свою папку независимо от того, откуда их запустили.
- `install_guide.md` — подробный гайд с нуля: проверка Python, установка,
  типовые ошибки и их решения.

-Статус проекта

RapidTag — прикладной MVP для кликового набора кабельных бирок из PDF-схем.
Публичный репозиторий предназначен для знакомства с кодом и обратной связи.
Проект не обещает промышленную готовность, сетевую печать или поддержку всех
вариантов инженерных обозначений. 

-Быстрый запуск для Windows

1. Установить Python.
2. Скачать ZIP.
3. Распаковать архив.
4. Запустить setup.bat.
5. Запустить start.bat.
